# Silksong Besties

Co-op Hollow Knight: Silksong for two. This repo only holds the finished mod files - it is the download page.

## Install (once)

1. Close Silksong.
2. Download **Install-Silksong-Besties.bat** from the [latest release](https://github.com/Jacobalicious/silksongbesties-releases/releases/latest) and double-click it.
   If Windows says "Windows protected your PC", click **More info** then **Run anyway**.
3. Start Silksong from Steam. The main menu has a **Start Multiplayer** button.

Updates install themselves every time the game starts.

Based on [SSMP](https://github.com/Extremelyd1/SSMP) (LGPL-2.1); source available on request.
